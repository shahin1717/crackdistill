# How to run each notebook on Kaggle

Generated by `scripts/build_final_notebooks.py` — regenerate instead of editing.

## Quick start (Stage A)

For each notebook:
1. Import it into Kaggle.
2. Set **GPU T4** and **Internet On**.
3. **+ Add Input** → `distill-datasetforme`.
4. **Save & Run All (Commit)**.

Each one takes about 2–3 hours, so 4 Kaggle accounts or sessions can run them in parallel.

| Order | Notebook | What it is |
| :---: | :--- | :--- |
| 1 | `A1_baseline_d4_seed0` | baseline, flips/rotations |
| 1 | `A2_mask_kd_d4_seed0` | SAM KD, plain |
| 2 | `A4_baseline_ultra_aug_seed0` | baseline, normal YOLO augmentation |
| 3 | `A5_mask_kd_gated_d4_seed0` | SAM KD, only inside the crack box and only where SAM agrees with the ground truth |
| 4 | `A3_gt_soft_d4_seed0` | blurred-GT control |

**Quick check in each log:**
- `Seed: 0` and `overlap_mask=False`.
- KD notebooks (A2, A5) also show `Found 2196 teacher logit files`.

**Send back:** the five executed `.ipynb` files. If you can, also download `results/*.json` and `best.pt` from
each notebook's Output tab. I need the `best.pt` files for the full-photo tiled test, which runs locally and is
inference only.

Details for each step follow below.

## Settings (every notebook)

1. Kaggle → **Create → New Notebook → File → Import Notebook** → upload the `.ipynb`.
2. Right panel: **Accelerator: GPU T4** (T4 x2 also works; only one GPU is used) · **Internet: On**.
3. **+ Add Input** → attach the inputs listed below. Nothing else needs editing — seeds, paths and the
   `ultralytics==8.4.60` pin are baked in.
4. **Save Version → Save & Run All (Commit)**. ~3 h per training notebook on a T4.
5. When it finishes, open the version → **Output**, download the files listed below.

## What the inputs must contain

Attach the same dataset to every notebook (e.g. `distill-datasetforme`). Step 1 searches all of `/kaggle/input`:

```
<attached dataset>/            e.g. distill-datasetforme (/kaggle/input/datasets/<owner>/distill-datasetforme)
├── .../crack500/              raw Crack500: a folder that contains traincrop/ (+ valcrop/ testcrop/ valdata/ testdata/)
│                              (or a converted YOLO folder with dataset.yaml)
└── .../teacher_logits/        Mask-KD only: crack500_<stem>_logits.npy  (teacher_logits_box/ also works)
```

- The raw `crack500/` folder (the one containing `traincrop/`) is used wherever it sits. Other datasets in
  the same input (`combined_yolo`, `crack500_yolo_augmented`, `deepcrack_yolo`, ...) are ignored.
- Step 2 then checks the split sizes are exactly **1896 / 348 / 1124** and stops the run otherwise.
- `valdata/` is needed for the extra uncropped-val evaluation in Step 4; without it that part is skipped.
- Attach **one** dataset that has a logits folder. If two are attached, whichever `teacher_logits*` folder the walk finds first is used.

- **Baseline + D4 augmentation:** Teacher logits are not read, even if attached.
- **Mask-KD from SAM 2 + D4 augmentation:** Without logits it tries to generate them with SAM 2 (untested on Kaggle, hours) — attach them.
- **GT-Soft Control + D4 augmentation:** Never uses SAM logits; it generates 1896 blurred-GT targets itself in Step 2.
- **Baseline + Ultralytics default augmentation (reference):** Teacher logits are not read, even if attached.
- **Box-cropped, GT-gated Mask-KD + D4 augmentation:** Without logits it tries to generate them with SAM 2 (untested on Kaggle, hours) — attach them.

**Every training log** must also show `Seed: <S>` and `overlap_mask=False`, and must **never** show
`Redirecting logits_dir`, `Missing letterbox metadata` or `No teacher logits ... matched` (in strict mode the
last two stop the run).
- A1-A3, A5: `D4 augmentation ON` and `mosaic=0.0` in the Ultralytics args.
- A4: **no** `D4 augmentation ON` line, and `mosaic=1.0`, `fliplr=0.5`, `scale=0.5` in the args.

## Run order

1. `A1_baseline_d4_seed0` and `A2_mask_kd_d4_seed0` first (the decisive pair), then `A4_baseline_ultra_aug_seed0`.
2. `A5_mask_kd_gated_d4_seed0`, then `A3_gt_soft_d4_seed0`.
3. Send the five executed notebooks back; the decision gate in `docs/KD_DESIGN_v2.md` picks what runs next.

## After downloading (local)

Put each `best.pt` at `checkpoints/<arm>_seed<S>.pt` (git-ignored) and each results JSON in
`results/kaggle/` (val metrics, tracked). Then, once all training is done:

```bash
conda activate distill
for f in checkpoints/*_seed*.pt; do
  n=$(basename "$f" .pt); arm=${n%_seed*}; seed=${n##*_seed}
  python scripts/evaluate_canonical_test_set.py --weights "$f" --arm "$arm" --seed "$seed"   # -> results/test/
done
python scripts/aggregate_multiseed_results.py --results-dir results/test --metric in_domain_mask_mAP50
```
