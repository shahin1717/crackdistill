# How to run each notebook on Kaggle

Generated by `scripts/build_final_notebooks.py` — regenerate instead of editing.

## Settings (every notebook)

1. Kaggle → **Create → New Notebook → File → Import Notebook** → upload the `.ipynb`.
2. Right panel: **Accelerator: GPU T4** (T4 x2 also works; only one GPU is used) · **Internet: On**.
3. **+ Add Input** → attach the inputs listed below. Nothing else needs editing — seeds, paths and the
   `ultralytics==8.4.60` pin are baked in.
4. **Save Version → Save & Run All (Commit)**. ~3 h per training notebook on a T4.
5. When it finishes, open the version → **Output**, download the files listed below.

## What the inputs must contain

Step 1 of each notebook walks `/kaggle/input` and links the first match it finds:

```
<attached dataset>/            e.g. distill-datasetforme (/kaggle/input/datasets/<owner>/distill-datasetforme)
├── .../crack500/              raw Crack500: a folder that contains traincrop/ (+ valcrop/ testcrop/ valdata/ testdata/)
│                              (or a converted YOLO folder with dataset.yaml)
└── .../teacher_logits/        Mask-KD only: crack500_<stem>_logits.npy  (teacher_logits_box/ also works)
```

- `valdata/` is needed for the extra uncropped-val evaluation in Step 4; without it that part is skipped.
- Attach **one** dataset that has a logits folder. If two are attached, whichever `teacher_logits*` folder the walk finds first is used.

- **Baseline (No KD):** Teacher logits are not read, even if attached.
- **Mask-KD from SAM 2 (Box Prompts):** Without logits it tries to generate them with SAM 2 (untested on Kaggle, hours) — attach them.
- **GT-Soft Control (Blurred Ground Truth):** Never uses SAM logits; it generates 1896 blurred-GT targets itself in Step 2.

**Every training log** must also show `Seed: <S>` and, in the Ultralytics args line, `mosaic=0.0` and
`overlap_mask=False`. It must **never** show `Redirecting logits_dir`, `Missing letterbox metadata`
or `No teacher logits ... matched` (in strict mode the last two stop the run).

## Run order

1. Pairs first, same seed: `1_baseline_seed0` + `2_mask_kd_seed0`, then seeds 1–4.
2. `3_gt_soft_seed0..2`.
3. Tier 2 only if the Mask-KD − baseline difference is clearly positive (see `EXPERIMENTS.md`).

## After downloading (local)

Put each `best.pt` at `checkpoints/<arm>_seed<S>.pt` (git-ignored) and each results JSON in
`results/kaggle/` (val metrics, tracked). Then, once all training is done:

```bash
conda activate distill
for f in checkpoints/*_seed*.pt; do
  n=$(basename "$f" .pt); arm=${n%_seed*}; seed=${n##*_seed}
  python scripts/evaluate_canonical_test_set.py --weights "$f" --arm "$arm" --seed "$seed"   # -> results/test/
done
python scripts/aggregate_multiseed_results.py --results-dir results/test --metric in_domain_mask_mAP50
```
