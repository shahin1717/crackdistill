# Crack-Distill 🛣️

**SAM 2 (Teacher) → YOLOv8-seg (Student) Knowledge Distillation for Road Surface Damage Segmentation**

Crack-Distill is a real-time pavement crack instance segmentation framework. It uses **Knowledge Distillation (KD)** to transfer structural detail and boundary uncertainty ("dark knowledge") from a powerful Segment Anything 2 (SAM 2) teacher model to a lightweight, real-time YOLOv8-seg student model.

At deployment time, you run the **YOLOv8-seg student alone**—achieving ultra-fast real-time inference (over 100 FPS) with zero dependency on SAM 2, while retaining the segmentation quality of the large teacher model.

## 📐 Project Architecture & KD Loss Functions

Our distillation pipeline goes beyond simple hard-label training by transferring three levels of teacher representation to the student:

```
  ┌─────────────────────────────────────────────────────────┐
  │                 SAM 2 Teacher Encoder                   │
  └────────────────────────────┬────────────────────────────┘
                               │ (MSE Loss on Aligned Scales)
                               ▼
  ┌─────────────────────────────────────────────────────────┐
  │             Student Backbone (YOLOv8-seg)               │
  └────────────────────────────┬────────────────────────────┘
                               │
                               ▼
  ┌─────────────────────────────────────────────────────────┐
  │             Student Segment Head Output                 │
  └────────────────────────────┬────────────────────────────┘
                               │ (KL Divergence + Uncertainty BCE)
                               ▼
             Distillation Target: Soft Logits Mask
```

### 1. Boundary-Aware Loss ($L_{\text{boundary}}$)
Road cracks are extremely thin and wind-like. Pixels on the boundaries of cracks contain the most uncertainty. In the teacher's pre-sigmoid logits, boundary pixels hover around $0.0$ (sigmoid probability $\approx 0.5$). 
The student is trained using a **Binary Cross-Entropy (BCE)** loss weighted by the teacher's soft prediction uncertainty. Pixel weights are defined as:
$$W_{\text{boundary}} = 1.0 - 2 \cdot |P_{\text{teacher}} - 0.5|$$
This forces the student to pay critical attention to fine-grained boundary pixels where the teacher itself is uncertain.

### 2. Soft Mask KD Loss ($L_{\text{mask\_kd}}$)
Instead of thresholding SAM 2's masks into hard binary targets, we compute the **Kullback-Leibler (KL) Divergence** on the soft Bernoulli probabilities generated by scaling the raw logits with a temperature parameter $T = 2.5$. This preserves the "dark knowledge" (e.g. geometric gradients, continuity details) that would otherwise be destroyed by binary labels.

### 3. Intermediate Feature Alignment ($L_{\text{feature}}$)
We match the intermediate feature representations of the student's backbone layers (specifically stages 2, 5, and 8) with SAM 2's high-resolution encoder features. We use dynamic $1\times1$ convolutional projection layers to align the channel dimensions and compute a **Mean Squared Error (MSE)** loss on the aligned feature maps.

### 4. Progressive Distillation Flow
To prevent gradient conflicts between the newly initialized projection layers and the student's detection heads, training is split into two progressive stages:
* **Stage 1 (Backbone Alignment):** The Segment head is frozen. The backbone features are trained to align directly with SAM 2 features.
* **Stage 2 (End-to-End Joint KD):** The entire network is unfrozen, training task loss and soft mask KD losses together.

## 📊 Experimental Results

Experiments conducted on the combined Crack500 + DeepCrack cropped datasets and the Crack500 uncropped dataset yield the following metrics:

| Model / Experiment | Cropped val mAP50-seg | Cropped val mAP50-box | Uncropped val mAP50-seg | Uncropped val mAP50-box |
| :--- | :---: | :---: | :---: | :---: |
| **Baseline (Fine-tune, No KD)** | **0.5352** | **0.5651** | 0.0225 | 0.0514 |
| **Pseudo-Labels (Hard SAM Targets)** | 0.4331 | 0.4776 | 0.0811 | 0.1233 |
| **Full KD (Ours)** | 0.5229 *(-2.3%)* | 0.5612 *(-0.7%)* | **0.1151** *(+411%)* | **0.1371** *(+167%)* |

### Why We Train on Crops but Test with Tiling
* **Resizing drops details:** Feeding a raw $2000 \times 1500$ uncropped image directly to a model with a $512 \times 512$ input size forces a downscale operation. Squeezing a massive road image shrinks crack widths below 1 pixel, causing them to disappear.
* **Tiling preserves resolution:** During testing, we slide a $512 \times 512$ window across the large uncropped image, run the model on each patch at full native resolution, and stitch the predictions back together. This ensures the model tests at the exact same resolution it trained on.

## ⚙️ Configuration & Setup

Open `configs/config.yaml`. You only ever need to configure these parameters:

```yaml
data:
  datasets:
    - name: combined
      path: data/datasets/combined_yolo
      format: yolo

student:
  backbone: yolov8n-seg   # student model architecture

distillation:
  progressive:
    enabled: true
    stage1_pct: 0.30     # 30% of epochs in backbone alignment
    stage2_pct: 0.70     # 70% of epochs in joint end-to-end KD
```

## 🚀 Setup & Execution Pipeline

Run these commands in order from the project root inside your conda environment:

### 1. Preprocess & Convert Datasets
Converts binary masks into YOLO-compatible segment boundary polygons:
```bash
# Convert Crack500
python scripts/convert_crack500.py --src data/datasets/crack500 --dst data/datasets/crack500_yolo

# Convert DeepCrack (80/20 train/val split)
python scripts/convert_deepcrack.py --src data/datasets/deepcrack --dst data/datasets/deepcrack_yolo
```

### 2. Generate SAM 2 Teacher Logits
Runs SAM 2 using bounding boxes derived from the ground-truth annotations to generate offline pre-sigmoid logits and feature maps:
```bash
# Generate Crack500 logits
python scripts/generate_teacher_logits.py --resume

# Generate DeepCrack logits
python scripts/generate_teacher_logits.py \
    --img-dir data/datasets/deepcrack/train_img \
    --mask-dir data/datasets/deepcrack/train_lab \
    --prefix deepcrack_ \
    --resume
```

### 3. Merge into Combined Dataset
Merges files from both datasets into a single training and evaluation split with non-conflicting prefixes:
```bash
python scripts/combine_datasets.py
```

### 4. Run Distillation Experiments
```bash
# Run baseline fine-tuning (no KD)
python scripts/run_experiments.py --exp baseline_finetune

# Run pseudo-label training (hard SAM masks, no KD)
python scripts/run_experiments.py --exp pseudo_labels

# Run the complete progressive knowledge distillation pipeline
python scripts/run_experiments.py --exp full_kd
```

### 5. Evaluate Weights Directly
Evaluate any trained model on validation splits without re-running training:
```bash
# Evaluate on cropped validation set
python scripts/test_model.py --val --model runs/crack_distill_full_kd_instance_seg_yolov8n-seg/weights/best.pt --data data/datasets/combined_yolo/dataset.yaml

# Evaluate on uncropped validation set
python scripts/test_model.py --val --model runs/crack_distill_full_kd_instance_seg_yolov8n-seg/weights/best.pt --data data/datasets/crack500_uncropped_yolo/dataset.yaml
```

## 🛠️ Folder & Scripts Structure

* **[distillation/](distillation/)**: Core KD implementation.
  * [kd_trainer.py](distillation/kd_trainer.py): Custom PyTorch wrapper that hooks into intermediate features, handles channel-projecting 1x1 convolutions, and overlays KD losses inside the training step.
  * [trainer.py](distillation/trainer.py): Higher-level trainer wrapper orchestrating progressive freezing/unfreezing epochs.
* **[scripts/](scripts/)**: Utilities for data preparation, logit generation, and evaluation.
  * [generate_teacher_logits.py](scripts/generate_teacher_logits.py): Offline logits exporter.
  * [test_model.py](scripts/test_model.py): Speed and segmentation metric validation.
* **[configs/](configs/)**: Experiment parameters and configuration files.

## 💻 Load & Deploy Model

At deployment time, SAM 2 is not needed. Run your lightweight distilled student directly:

```python
from ultralytics import YOLO

# Load the distilled student weights
model = YOLO("runs/crack_distill_full_kd_instance_seg_yolov8n-seg/weights/best.pt")

# Perform real-time inference
results = model.predict("road_surface_image.jpg", conf=0.25, imgsz=512)

# Save or display
results[0].show()
results[0].save(filename="output_segmented.jpg")
```
