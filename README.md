# CrackDistill

Offline knowledge distillation from **SAM 2 Large** (teacher, 224M params, box-prompted mask logits cached
once) into **YOLOv11n-seg** (student, 2.84M params) for road-crack instance segmentation on Crack500.
At inference the student runs alone.

> **Status (2026-09-28):** all KD results produced before this date are invalid: the teacher was
> misaligned and mispaired during training. The confirmatory study has not been run yet, so this repo
> currently makes **no** accuracy claim. See [`EXPERIMENTS.md`](EXPERIMENTS.md).

```
SAM 2 Large --(offline, once)--> teacher logits <stem>_logits.npy (M x 256 x 256)
                                          |
YOLOv11n-seg --> KDSegmentationTrainer: task loss + Bernoulli mask-KL (T=3.7769, W=0.9612)
                 (teacher letterbox-warped onto the student canvas, paired as teacher[target_gt_idx])
```

## Layout

| Path | What |
| :--- | :--- |
| `distillation/kd_trainer.py` | Trainer: letterbox warp, instance pairing, KD losses, strict-mode guards |
| `inference/tiled_inference.py` | Gaussian-weighted sliding-window inference for full-size photos |
| `final_notebooks/` | Self-contained Kaggle notebooks, generated by `scripts/build_final_notebooks.py` |
| `scripts/generate_teacher_logits.py` | SAM 2 teacher logits (offline) |
| `scripts/generate_gt_soft_logits.py` | Blurred-GT targets for the control arm |
| `scripts/verify_alignment.py` | Teacher-vs-GT alignment on the real training transforms → `reports/alignment_verification.json` |
| `scripts/evaluate_canonical_test_set.py` | Canonical test split + 200 full-size test photos (tiled vs direct) |
| `scripts/aggregate_multiseed_results.py` | Per-arm stats and seed-paired comparisons |
| `reports/*.tex` | Manuscript drafts; their numbers predate the fixes and must be rewritten |

## Run

- **Kaggle training:** see [`final_notebooks/README.md`](final_notebooks/README.md).
- **Local** (`conda activate distill`, Ultralytics 8.4.60):

```bash
python -m unittest discover -s tests                                            # 56 tests
python scripts/verify_alignment.py --logits-dir data/teacher_logits_box         # alignment gate
python scripts/evaluate_canonical_test_set.py --weights <best.pt> --arm mask_kd --seed 0
python scripts/aggregate_multiseed_results.py --results-dir results/test --metric in_domain_mask_mAP50
```
